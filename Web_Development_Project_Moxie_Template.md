
# Web Development Project – Master Phase Template

This template is designed for use in Moxie as a reusable project template.
Each **PHASE** represents a parent task, and bullet points represent subtasks.

---

## PHASE 1: Prep & Kickoff
- Contract signed & initial payment received
- Project created in Moxie
- Client intake form reviewed
- Kickoff call completed
- Project goals & success metrics defined
- Scope & deliverables confirmed
- Timeline & milestones agreed upon
- Client communication expectations set

---

## PHASE 2: Strategy & Content Planning
- Business goals & target audience defined
- Competitor & industry research
- Website purpose & primary CTA identified
- Sitemap / page list created
- Navigation & user flow planned
- SEO foundation (keywords, pages, intent)
- Platform & tech stack confirmed
- Strategy approval from client

---

## PHASE 3: Visual Brand Identity
- Brand assets collected (logo, fonts, colors)
- Visual style direction established
- Inspiration / reference examples shared
- Homepage visual direction defined
- UI consistency rules set
- Brand & design direction approved

---

## PHASE 4: Content Development
- Page copy written or received
- Copy reviewed for clarity & conversion
- Images selected or sourced
- Image optimization completed
- Content formatted for web use
- Final content approval

---

## PHASE 5: Build & Design
- Development environment set up (local/staging)
- Theme / builder configured
- Page templates created
- Content implemented into pages
- Responsive layout adjustments
- Accessibility & usability checks

---

## PHASE 6: Tech Integrations & Automations
- Contact forms created & tested
- Email integrations connected
- CRM or marketing tools connected
- Analytics installed
- Security & performance plugins configured
- Backups & caching set up
- Integration testing completed

---

## PHASE 7: Revising & Optimizing
- Internal QA review completed
- Client review round initiated
- Client feedback collected
- Revisions implemented
- Final optimization pass
- Client final approval

---

## PHASE 8: Launch & Marketing Momentum
- Pre-launch checklist completed
- Domain & DNS verified
- SSL confirmed
- Site migrated to live environment
- Final live testing
- Analytics & tracking verified
- Launch confirmation sent to client

---

## PHASE 9: Test & Launch (Post-Launch Validation)
- Post-launch monitoring
- Bug fixes (grace period)
- Client walkthrough / training
- Documentation delivered
- Maintenance plan activated (if applicable)
- Final invoice sent
- Project marked complete

---

**Usage Tip:** Duplicate this template for each new web development project and adjust subtasks or durations based on scope.
