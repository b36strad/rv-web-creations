### Quick Deploy Steps

1. **Open Netlify**: https://app.netlify.com/
2. **Deploy manually**: Sites → Add new site → Deploy manually
3. **Drag folder**: Drag `templates/shop/` folder to Netlify
4. **Rename site**: Change to `rvweb-shop-demo`
5. **Get URL**: https://rvweb-shop-demo.netlify.app
