## 🎓 Frequently Asked Questions

### General Questions

**Q: Do I own the website after it's built?**  
A: Yes! You own all code, content, and design. We provide full source code.

**Q: Can I make updates myself?**  
A: Starter package requires developer. Growth package (WordPress) gives you full editing control with training.

**Q: What if I need help after launch?**  
A: Support period included with each package. After that, we offer maintenance plans or hourly support.

**Q: Do you write the content?**  
A: Content is typically client-provided. We offer copywriting as add-on service ($1,000-3,000).

**Q: Will my website work on mobile?**  
A: Yes! All packages include fully responsive design for mobile, tablet, and desktop.

**Q: How many revisions do I get?**  
A: Depends on package tier (1-3 rounds). Additional revisions available at hourly rate.

**Q: What if the project takes longer than estimated?**  
A: Fixed-price packages protect you. Timeline delays due to client feedback/content don't affect price.

**Q: Can you help with domain and hosting?**  
A: Yes! We can register domain, set up hosting, and handle all technical setup.

### Technical Questions

**Q: What technology do you use?**  
A: Starter uses modern HTML/CSS/JavaScript. Growth uses WordPress. Custom uses best technology for your needs.

**Q: Will my site be fast?**  
A: Yes! We optimize all sites for speed. Typically load in under 3 seconds.

**Q: Is SEO included?**  
A: Basic on-page SEO included. Advanced SEO available as ongoing service ($500-1,500/month).

**Q: Can you integrate with my existing systems?**  
A: Depends on complexity. Simple integrations often included. Complex integrations may require Custom package.

**Q: Do you provide analytics?**  
A: Yes! Google Analytics setup included in all packages.

**Q: Is the site secure?**  
A: Yes! SSL certificate, security best practices, and (for Growth) security plugins included.

### Pricing Questions

**Q: Why are your prices lower than some agencies?**  
A: We use proven templates, reducing development time. Lower overhead = savings passed to you.

**Q: Can I pay in installments?**  
A: Yes! See payment structure section. Milestone-based payments available.

**Q: What's not included in the price?**  
A: See "What's NOT Included" section above. Domain, hosting, and ongoing fees are separate.

**Q: Are there any hidden fees?**  
A: No. Fixed-price quotes include everything specified in proposal.

**Q: What if I want features from multiple packages?**  
A: We can create custom proposal mixing features from different packages.
