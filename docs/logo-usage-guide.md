# Logo Usage Guide for Business Documents
## RV Web Creations LLC

**Last Updated:** December 11, 2025

## Overview

This guide provides recommendations for using the RV Web Creations logo across various business documents including invoices, proposals, contracts, and other professional materials.

---

## Recommended Logo Versions by Document Type

### Invoices

**Recommended Version:** Horizontal Logo (Medium) - 600 × 150px

**Placement:**
- Top left corner of invoice header
- Contact information on the right side
- Leave adequate white space around logo

**Format:**
- PNG with transparent background
- Alternatively, SVG for perfect scaling

**Example Layout:**
```
[LOGO]                              RV Web Creations LLC
                                    [Business Address]
                                    [Email] | [Phone]
                                    
INVOICE #001
Date: [Date]
Due: [Due Date]
```

---

### Proposals

**Cover Page:** Horizontal Logo (Large) - 800 × 200px
- Centered on cover page
- Creates strong first impression
- Prominent branding

**Interior Pages:** Horizontal Logo (Small) - 400 × 100px
- Top left or center of header
- Smaller to not dominate content
- Consistent across all pages

**Placement:**
- Cover: Center of page, 1/3 from top
- Interior: Header, left-aligned or centered
- Footer: Optional small icon (40-60px)

**Format:**
- PNG with transparent background
- High-resolution for print proposals (use 2400 × 600px version)

**Example Cover Page Layout:**
```
                    [LARGE LOGO CENTERED]
                    
                    Web Design Proposal
                    
                    Prepared for: [Client Name]
                    Prepared by: RV Web Creations LLC
                    Date: [Date]
```

### Contracts & Service Agreements

**Recommended Version:** Horizontal Logo (Medium) - 600 × 150px

**Placement:**
- Top center or top left of first page only
- Do not repeat on subsequent pages
- Signature page: Optional small logo in footer

**Format:**
- PNG with transparent background
- Professional, not overwhelming

**Example Header Layout:**
```
                [LOGO CENTERED]
                
        WEB DESIGN & DEVELOPMENT SERVICE AGREEMENT
        
        Between: RV Web Creations LLC
        And: [Client Name]
        
        Effective Date: [Date]
```

### Quotes & Estimates

**Recommended Version:** Horizontal Logo (Small) - 400 × 100px

**Placement:**
- Above name and contact details

### Business Cards

**Recommended Version:** Business Card (Print) - 3000 × 750px

**Placement:**
- Front: Prominent, centered or left-aligned
- Back: Optional smaller version

**Format:**
- High-resolution PNG (300 DPI)
- Print-ready quality

**Print Specifications:**
- Minimum 300 DPI for printing
- CMYK color mode (convert if needed)
- Bleed: Add 0.125" bleed if required by printer

## File Format Recommendations

### PNG (Recommended for Most Uses)
- **Use for:** Invoices, proposals, contracts, emails
- **Advantages:** 
  - Transparent background
  - Universal compatibility
  - Good quality at set size
- **Export from:** `logo-export-advanced.html`

### SVG (Best for Scalability)
- **Use for:** Web documents, presentations that support SVG
- **Advantages:**
  - Perfect scaling at any size
  - Smallest file size
  - Crisp on any display
- **Source:** Already in your website code

### Print (High-Resolution PNG)
- **Use for:** Business cards, printed proposals, posters
- **Requirements:**
  - 300 DPI minimum
  - Large dimensions (2400px+ width)
- **Export from:** `logo-export-advanced.html` (Print or Business Card versions)

## Color Specifications

### Primary Colors
- **Navy Blue:** #1f4f7b (RGB: 31, 79, 123)
- **Gold:** #f8b400 (RGB: 248, 180, 0)
- **White:** #ffffff (RGB: 255, 255, 255)

- **White:** For social media squares or specific needs
- **Dark:** Ensure sufficient contrast if placing on dark backgrounds

## Sizing Guidelines

### Minimum Sizes
- **Digital documents:** 300px width minimum
- **Print documents:** 2 inches width minimum at 300 DPI
- **Email signatures:** 250-400px width
- **Business cards:** 2.5 inches width minimum

### Maximum Sizes
- **Invoice/Contract headers:** Do not exceed 1/5 of page height
- **Proposal covers:** Do not exceed 1/2 of page width
- **Email signatures:** Do not exceed 450px width (file size concerns)

---

## White Space & Margins

### Clear Space
Maintain clear space around logo equal to the height of the "R" in the icon:
- Minimum: 20% of logo height
- Recommended: 30% of logo height on all sides

### Document Margins
- **Top margin:** 0.5-1 inch from page edge to logo
- **Side margins:** 0.5-0.75 inch from page edge
- **Bottom:** If logo in footer, 0.5 inch from bottom

## Do's and Don'ts

### Do:
✓ Use approved logo versions from export tool
✓ Maintain aspect ratio (do not stretch or squash)
✓ Ensure adequate white space around logo
✓ Use transparent background for professional appearance
✓ Keep logo crisp and clear (use appropriate resolution)
✓ Maintain consistent placement across document types

### Don't:
✗ Change logo colors
✗ Rearrange logo elements
✗ Add effects (shadows, gradients, etc.)
✗ Place on busy backgrounds
✗ Rotate or distort logo
✗ Use low-resolution versions for print
✗ Overcrowd logo with text or graphics

## Accessibility Considerations

### Alt Text
When using logo in digital documents:
- **Invoice/Contract:** "RV Web Creations LLC logo"
- **Email signature:** "RV Web Creations - Custom small business websites"

### Contrast
- Ensure sufficient contrast between logo and background
- Navy blue (#1f4f7b) passes WCAG AA on white
- Gold (#f8b400) needs dark background for accessibility

## Software-Specific Tips

### Microsoft Word
1. Insert → Pictures
2. Use PNG with transparent background
3. Right-click → Wrap Text → In Front of Text
4. Position and resize as needed
5. Lock aspect ratio when resizing

### Google Docs
1. Insert → Image → Upload from computer
2. Use PNG with transparent background
3. Image options → Text wrapping → Wrap text
4. Resize maintaining proportions

### Adobe PDF
1. Use high-resolution PNG (600-800px for medium size)
2. Embed fonts if using SVG
3. Save as PDF/X for print

### Email (HTML)
```html
<img src="logo.png" alt="RV Web Creations LLC" width="400" style="display: block; max-width: 100%; height: auto;">
```

## Print Preparation Checklist

Before sending logos to printer:

- [ ] Resolution is 300 DPI minimum
- [ ] Dimensions are correct for print size
- [ ] Color mode is CMYK (convert from RGB if needed)
- [ ] Bleed is added if required (usually 0.125")
- [ ] File format is acceptable (usually PDF, PNG, or TIFF)
- [ ] Proof has been reviewed and approved
- [ ] Backup files saved in multiple formats

## Quality Control

### Before Using Logo in Documents:

1. **Visual Check**
   - Is logo crisp and clear?
   - Are colors accurate?
   - Is aspect ratio correct?

2. **Size Check**
   - Is logo readable at intended size?
   - Does it meet minimum size requirements?
   - Is it proportional to document?

3. **Placement Check**
   - Is there adequate white space?
   - Is it consistently placed?
   - Does it align with document grid?

4. **File Check**
   - Is resolution appropriate (72 DPI screen, 300 DPI print)?
   - Is file format correct?
   - Is file size reasonable?

## Troubleshooting

### Logo Appears Blurry
- **Problem:** Resolution too low
- **Solution:** Use larger PNG or SVG format

### Logo Has White Box Around It
- **Problem:** Not using transparent background
- **Solution:** Re-export as PNG with transparency

### Logo Too Large in Email
- **Problem:** File size too big or dimensions too large
- **Solution:** Use 400px or smaller version, compress file

### Logo Prints Poorly
- **Problem:** Resolution insufficient
- **Solution:** Use 300 DPI print version (2400px+ width)

### Colors Look Different When Printed
- **Problem:** RGB to CMYK color shift
- **Solution:** Convert to CMYK, adjust colors if needed, request proof
