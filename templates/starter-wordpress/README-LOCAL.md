# WordPress Starter Package for Local by Flywheel

## How to Use

1. **Drag the `starter-wordpress` folder into Local by Flywheel**
   - This folder now contains a full WordPress installation, including all core files, and a `wp-content` directory with your custom starter theme and plugins folders.

2. **Start the site in Local**
   - Local will recognize the structure and prompt you to set up the site.

3. **Customize as needed**
   - Add your themes to `wp-content/themes/` and plugins to `wp-content/plugins/`.
   - The included files in `wp-content` will not be overwritten by WordPress updates.

## Notes
- This package is based on the latest official WordPress release.
- You can safely delete default themes or plugins you do not need.
- For updates, repeat this process or use WordPress's built-in update tools.
